Financement de la formation

Combien l'OPCO de votre entreprise peut-il financer ?

Entrez le nom, le SIREN ou le site web d'une entreprise. Vous obtenez son OPCO officiel et le budget formation qu'il prend en charge cette année, avec chaque source.

Essayer :

Sous le capot

Un agent Claude Code, une interface sans serveur

  1. 01

    Identifier

    Nom, SIREN ou site web vers l'entreprise, son effectif et sa convention collective, via l'API Recherche d'entreprises.

  2. 02

    Trouver l'OPCO

    Lecture de la table officielle SIRET-OPCO de France compétences. Aucune déduction : l'OPCO est celui déclaré.

  3. 03

    Lire le barème

    Un sous-agent Claude cherche les critères de l'OPCO pour la branche et l'année, et cite chaque montant. Commande /budget-opco.

  4. 04

    Calculer et vérifier

    Le calcul est fait par du code, jamais par le modèle. Un hook refuse toute fiche qui contient un montant sans source.

Le modèle orchestre et interprète. Le code calcule. Le hook vérifie.
